# Expense Tracker

HTML | CSS | JavaScript

A responsive tracker to add, categorize, and total income and expenses with automatic balance updates. JavaScript handles real-time calculations and form validation.

## Features

- Add income and expense transactions with a description, amount, and category
- Automatic balance, total income, and total expense updates
- Real-time form validation with inline error messages
- Delete individual transactions or clear them all
- Transactions persisted in `localStorage`
- Responsive layout for desktop and mobile

## Getting Started

Open `index.html` in any modern web browser.

## Project Structure

```
index.html   Markup and layout
style.css    Responsive styling
script.js    Transaction logic, validation, and balance calculations
```
